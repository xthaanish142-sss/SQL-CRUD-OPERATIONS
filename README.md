
# SQL CRUD OPERATIONS

## Introduction

SQL CRUD Operations is a database management project that demonstrates the four fundamental operations used to manage data in a relational database. CRUD stands for Create, Read, Update, and Delete.

This project uses SQL and SQLite to demonstrate how records can be inserted, retrieved, modified, and deleted from a database.

## Objectives

The main objectives of this project are to understand SQL concepts, learn CRUD operations, create database tables, and manage records efficiently.

## Technologies Used

- SQL
- SQLite
- GitHub

## CRUD Operations

### 1. CREATE

The CREATE operation is used to insert new records into a database table. It allows users to add new information and store it in the database.

### 2. READ

The READ operation is used to retrieve and display information stored in a database. The SELECT statement is used to access records.

### 3. UPDATE

The UPDATE operation is used to modify existing records in a database. It allows users to change specific information.

### 4. DELETE

The DELETE operation is used to remove unwanted records from a database table.

## Database Structure

The project uses a student table containing ID, Name, Age, Address, and Marks.

## Advantages

- Easy data management.
- Quick data retrieval.
- Simple record modification.
- Organized information storage.

## Conclusion

This project provides practical knowledge of SQL CRUD operations and demonstrates how SQLite can be used to manage database records efficiently.
